# Changelog

All notable changes to [Satche](https://github.com/satche), a multitool cross-platform <abbr title="Developer as a Service">DaaS</abbr>

## v1.3 (Work in progress)

- Hibernation mode while world map is explored using A* algorithm
- Apply <abbr title="Breadth-First Search">BFS</abbr> algorithm on `find-job` routine

## v1.2 (2025-08-22)

- Deploy [HES-SO](https://www.hes-so.ch/) framework in `learning` environment
- Add `machine-learning` to roadmap
- Improve global performances
- Validate `computer-science` <abbr title="Master of Science">MSc</abbr> in Engineering certificate

## v1.1 (2022-09-16)

- Deploy [HEIG-VD](https://heig-vd.ch/) framework in `learning` environment
- Add `back-end` to roadmap
- Global refactoring
- Validate `media-engineering` <abbr title="Bachelor of Science">BSc</abbr> certificate

## v1.0 (2016-04-01)

- Deploy `work` production environment
- Add Node.js support
- Add general contribution guidelines

## v0.3 (2012-02-29)

- Deploy [Eracom](https://eracom.ch/) framework in `learning` environment
- Add `user-experience` and `creative-coding` as dependencies to `curiosity` kernel module
- Add HTML, CSS and JavaScript language support
- Include basic Wordpress support
- Add `front-end` to roadmap

## v0.2 (2009-01-03)

- Add `computers`, `code`, and `new-technologies` as dependencies to `curiosity` kernel module
- Init `sandbox` environment to handle development of prototype applications
- Deploy local Archlinux installation on (legacy) computer
- Deploy web server on local environment
- Remove `cloud-computing` from roadmap

## v0.1 (1992-08-30)

- Initial public release
